KICKOFF WINS GIFTS — Godot 4 offline 3D migration foundation.

This is a new Android-first Godot project, separate from the former Expo 2D prototype. It contains a procedural 3D pitch, goals, player and opponent characters, ball, follow camera, touch buttons for movement/sprint/pass/shoot, a 90-second local match and local career save in user://career.cfg.

Open this folder with Godot 4.3 or newer and run scenes/main.tscn. Android export templates and Android SDK must be configured in Godot before exporting an APK.

STATUS: early 3D prototype only, not a finished Dream League Soccer-scale game. Full player animations, realistic ball physics, goalkeeper and referee AI, team formations, league menus, audio, performance tuning and Android device testing remain to be done.
